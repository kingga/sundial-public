# Sundial

Sundial counts the days until, or since, the dates that matter, on iPhone and Android.

- [Privacy Policy](https://kingga.github.io/sundial-public/privacy/)
- [Terms of Use](https://kingga.github.io/sundial-public/terms/)
- [Support](https://kingga.github.io/sundial-public/support/)

## Report a bug or request a feature

[Open an issue](https://github.com/kingga/sundial-public/issues/new/choose) and choose Bug report or Feature request. You need a GitHub account.

Issues here are public, so please don't post Event titles, photos or anything else private.

## Anything private

Email [contact.sundial.app@gmail.com](mailto:contact.sundial.app@gmail.com).

## About this repository

Sundial's source code isn't public. This repository holds the public issue tracker and, on the `gh-pages` branch, the pages above. Those pages are published automatically from the same text the app shows, so please suggest changes to them in an issue rather than a pull request.
